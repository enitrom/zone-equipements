INSTRUCTIONS D'INSTALLATION - THEME ENFANT ZONE EQUIPEMENTS
===========================================================

Ce dossier contient tous les fichiers nécessaires pour transformer votre site WordPress en une vitrine industrielle haut de gamme, basée sur le thème parent "Twenty Twenty-Four".

COMMENT INSTALLER :
-------------------
1. Téléchargez tous les fichiers situés dans le dossier /zone-equipements-child/.
2. Créez un fichier ZIP contenant tout le contenu de ce dossier (le dossier racine doit être zone-equipements-child).
3. Dans votre administration WordPress :
   - Allez dans Apparence > Thèmes.
   - Cliquez sur "Ajouter" puis "Téléverser un thème".
   - Choisissez le fichier ZIP que vous venez de créer.
   - Activez le thème.
4. Assurez-vous que le thème parent "Twenty Twenty-Four" est également installé sur votre site.

CARACTÉRISTIQUES INCLUSES :
---------------------------
- Couleurs personnalisées : Bleu Profond (#003366) et Orange Sécurité (#FF6600).
- Typographie : Intégration de "Inter" et "Space Grotesk" pour un look industriel.
- Patterns (Modèles) : Accédez à des blocs pré-conçus (Hero, Features Grid) dans l'éditeur.
- Compatibilité WooCommerce : Prêt pour le e-commerce industriel.
- Entièrement éditable : Modifiez l'en-tête, le pied de page et les modèles via l'Editeur de Site (FSE).

NOTES COMPLÉMENTAIRES :
-----------------------
- Vous pouvez ajouter un logo via Apparence > Éditeur > En-tête.
- Utilisez les "Composants Patterns" pour recréer rapidement les sections de la page d'accueil.
